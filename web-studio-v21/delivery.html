OWNERSHIP / INFRASTRUCTURE

Dobré předání
má jasná pravidla.

Před objednávkou si vyjasníme přístupy, odpovědnost a náklady. Zůstáváte schopni web provozovat i předat dál.

Vaše doména, obsah a přístupy.

Doménu registrujte na svůj účet. Předání zdrojového kódu, licence, data a přístupy jsou součástí výslovné dohody. Zálohy a způsob exportu stanovíme před spuštěním.

Doména / DNS / TLS

Doména a obnova na účtu zákazníka. DNS a HTTPS konfigurujeme podle dohody; přístupy předáváme.

Hosting / databáze / úložiště

Poskytovatel, kapacita, region a úhrada se vybírají podle projektu. Statický web nepotřebuje automaticky databázi.

Data / zálohy / export

Předem určíme retenční dobu, vlastnictví dat, frekvenci záloh a obnovu. Datové exporty musí mít popsaný formát.

Kód / licence / odchod

Zdrojový kód a licence podle smlouvy. Komerční pluginy mají vlastní podmínky. Přístup, migrace a ukončení péče se dohodnou písemně.

E-mail / analytika / soukromí

Firemní schránka a transakční poskytovatel jsou oddělené služby. Nezbytné kontaktní a právní údaje musí schválit provozovatel.

Po spuštění

Péče je volitelná. Bez servisní dohody nelze slíbit nepřetržitý dohled, zálohy či reakční časy.
