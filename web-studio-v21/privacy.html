Tento web neobsahuje kontaktní backend. Zadání a editace se ukládají lokálně ve vašem prohlížeči.

Editor ukládá výslovně uložené koncepty do localStorage. Zadání používá sessionStorage, dokud kartu nezavřete nebo koncept nevymažete. PawMaster demo si ukládá profil a dokončené povely lokálně. Soubory JSON a ZIP se vytvářejí v prohlížeči. Nevyužíváme analytické sledování.

Než se aktivuje sběr skutečných poptávek, provozovatel musí potvrdit svou identitu, veřejné kontakty, právní texty, poskytovatele a retenční podmínky. Tato demonstrace nevytváří smlouvu ani platbu.
