Vaše doména, obsah a přístupy.

Doménu registrujte na svůj účet. Předání zdrojového kódu, licence, data a přístupy jsou součástí výslovné dohody. Zálohy a způsob exportu stanovíme před spuštěním.

Na vašem účtu

Doména / DNS / TLS

Registrace a obnova domény na účtu zákazníka. DNS a HTTPS podle dohody; přístupy předáváme.

Podle skutečné potřeby

Hosting / databáze / úložiště

Poskytovatel, kapacita, region a úhrada se vybírají podle projektu. Statický web automaticky nepotřebuje databázi.

Předem popsaná obnova

Data / zálohy / export

Vlastnictví dat, retenční doba, frekvence záloh, test obnovy a formát exportu se stanoví před provozem.

Předání podle smlouvy

Kód / licence / odchod

Zdrojový kód a licence podle dohody. Komerční pluginy mají vlastní podmínky. Migrace a ukončení péče jsou popsané písemně.

Oddělené služby

E-mail / analytika / soukromí

Firemní e-mail, transakční poskytovatel, analytika a souhlas mají vlastní náklady a nastavení. Právní údaje potvrzuje provozovatel.
