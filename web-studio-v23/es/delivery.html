PROPIEDAD / DATOS / FUNCIONAMIENTO

Tu proyecto.
Control claro.

Dominio, código fuente, datos y accesos. Antes del lanzamiento definimos qué recibes y quién se encarga de cada parte.

Tu dominio, tu contenido y tus accesos.

Registra el dominio en tu propia cuenta. La entrega del código fuente, las licencias, los datos y los accesos forma parte de un acuerdo expreso. Definimos las copias de seguridad y la exportación antes del lanzamiento.

En tu cuenta

Dominio / DNS / TLS

Registro y renovación del dominio en la cuenta del cliente. DNS y HTTPS según lo acordado; entregamos los accesos.

Según las necesidades reales

Alojamiento / base de datos / almacenamiento

El proveedor, la capacidad, la región y el pago se eligen según el proyecto. Un sitio estático no necesita automáticamente una base de datos.

Restauración definida de antemano

Datos / copias de seguridad / exportación

La propiedad de los datos, el plazo de conservación, la frecuencia de las copias, la prueba de restauración y el formato de exportación se definen antes de la puesta en marcha.

Entrega según el contrato

Código / licencias / salida

Código fuente y licencias según lo acordado. Los complementos comerciales tienen sus propias condiciones. La migración y el fin del mantenimiento se describen por escrito.

Servicios separados

Correo / analítica / privacidad

El correo empresarial, el proveedor transaccional, la analítica y el consentimiento tienen costes y ajustes propios. El operador confirma los datos legales.

El mantenimiento es opcional

Después del lanzamiento

Sin un acuerdo de mantenimiento no se promete supervisión continua ni tiempos de respuesta. Las cuentas de Google/Apple, los servicios de pago y la infraestructura los paga la parte designada en el contrato.
