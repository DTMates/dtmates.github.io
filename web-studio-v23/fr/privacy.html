CE QUI EST RÉELLEMENT ENREGISTRÉ

Sans envoi
caché.

L’éditeur n’enregistre que les brouillons explicitement sauvegardés. PawMaster conserve le profil et les commandes terminées. Le cahier des charges reste dans sessionStorage jusqu’à la fermeture de l’onglet ou son effacement.

Un brouillon enregistré peut être remplacé ou supprimé dans les paramètres de stockage du navigateur. Progression et cahier des charges peuvent être effacés directement dans la démonstration. Le navigateur crée les fichiers JSON et ZIP. Nous n’utilisons ni suivi analytique ni fausse synchronisation cloud.

Avant d’activer la collecte réelle de demandes, l’exploitant doit confirmer son identité, ses coordonnées publiques, les textes légaux, les prestataires et les règles de conservation. Cette démonstration ne crée ni contrat ni paiement.

Sauvegarde temporaire lors du changement de langue

Lorsque vous changez la langue de l’interface, une copie temporaire est enregistrée dans ce navigateur pour conserver votre brouillon, l’historique d’annulation et le cahier des charges saisi. Elle est supprimée après une restauration réussie. Si le changement est interrompu, vous pouvez l’effacer dans les paramètres de données du site du navigateur. Rien n’est envoyé à un serveur.
