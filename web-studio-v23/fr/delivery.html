Votre projet.
Un contrôle clair.

Domaine, code source, données et accès. Avant le lancement, nous définissons ce que vous recevez et qui en est responsable.

Votre domaine, vos contenus et vos accès.

Enregistrez le domaine sur votre propre compte. La remise du code source, les licences, les données et les accès font l’objet d’un accord explicite. Les sauvegardes et le mode d’export sont définis avant le lancement.

Sur votre compte

Domaine / DNS / TLS

Enregistrement et renouvellement du domaine sur le compte client. DNS et HTTPS selon l’accord ; nous transmettons les accès.

Selon les besoins réels

Hébergement / base de données / stockage

Prestataire, capacité, région et paiement sont choisis selon le projet. Un site statique n’a pas automatiquement besoin d’une base de données.

Restauration définie à l’avance

Données / sauvegardes / export

Propriété des données, durée de conservation, fréquence des sauvegardes, test de restauration et format d’export sont définis avant l’exploitation.

Livraison selon le contrat

Code / licences / départ

Code source et licences selon l’accord. Les extensions commerciales ont leurs propres conditions. Migration et fin de maintenance sont décrites par écrit.

Services distincts

E-mail / statistiques / confidentialité

Messagerie professionnelle, prestataire transactionnel, statistiques et consentement ont leurs propres coûts et réglages. Les informations légales sont confirmées par l’exploitant.

La maintenance est facultative

Après le lancement

Sans contrat de maintenance, aucune surveillance continue ni aucun délai de réponse ne sont promis. Comptes Google/Apple, services de paiement et infrastructure sont payés par la partie désignée au contrat.
