Samostatné portfólio

Navštíviť verejný projekt

Publikované portfólio SvelteKit / Cloudflare Pages.

Publikované portfólio V16 používa statické zostavenie SvelteKit, galérie vlastných médií a ovládateľné porovnania; nová snímka zachytáva samostatnú verejnú návštevu 22. novembra 2026.

Samostatný verejný web sa úspešne otvoril vo viditeľnom Chrome; zachované overenie V16 dokladá sedem stránok a porovnania ovládané klávesnicou aj dotykom.

Navštívte fungujúce samostatné portfólio alebo si pozrite novú snímku verejného webu z prehliadača v rozlíšení 1440×1000.

Priame automatizované požiadavky vracali HTTP 403, ale viditeľný Chrome web otvoril; súkromný náborový kandidát V17 je z tejto prezentácie vylúčený.

Map Creator

Navštíviť verejný projekt

Vydaný platený mapový editor na stiahnutie pre miestny prehliadač.

Vrstvený prehliadačový editor používa indexované fantasy a wasteland ilustrácie, maľovanie terénu a návrhy Smart Terrain.

Zaznamenaný postup zahŕňa vrstvy, transformácie objektov, upraviteľné uloženie a načítanie a výstupy PNG, JSON a CSV.

Pozrite si skutočné snímky pracovného postupu a oficiálnu ponuku v1.19; stiahnutý editor používajte podľa jeho licencie.

Úplný platený editor tu nebeží; miestna v1.21 nie je overené verejné vydanie a šesť odovzdaní predstavuje štruktúrované dáta, nie natívne pluginy.

Unreal AutoMap

Lokálny nástroj / vo vývoji

Miestny nástroj na plánovanie a natívne úpravy v Unreal Engine.

Metadáta a obmedzené pokyny prevádza na plán operácií s terénom a objektmi, ktorý miestny adaptér Unreal aplikuje a overuje.

Zachované natívne testy zaznamenávajú umiestnenie objektov, úpravy terénu, uloženie a čisté znovuotvorenie, kolízie a skúšky hernej postavy.

Porovnajte skutočný areál pred a po z rovnakej kamery a sledujte označený záznam plánu, aplikácie a overenia.

Nebeží v prehliadači ani cloude; dvojica areálu je historický samostatný test Kenney CC0, nie čerstvý natívny beh, a produkčný ingest zostáva blokovaný.

3D Asset Studio

Lokálny nástroj / vo vývoji

Upraviteľné recepty Blender a postup overovania assetov v Unreal.

Originálne geometrické recepty a editovateľné zdroje prepájajú UV/PBR materiály, samostatné mesh moduly, LOD, kolízie a vybrané natívne importy.

Verzované zdroje a exporty zachovávajú jednotlivé modely; záznamy dokladajú vybrané kontroly importu, LOD, kolízií a opätovného otvorenia.

Pozrite si skutočné porovnanie bukového materiálu a natívny kontext a sledujte vysvetlený postup od editovateľného zdroja k exportu.

Umelecké a výkonové posúdenie zostáva otvorené; dvojica buka je materiálová štúdia Blender s rovnakou geometriou, nie render Unreal ani schválenie produkcie.
